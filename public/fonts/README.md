`pleading-emoji.ttf` is a single-codepoint subset (U+1F97A, 🥺) of the Noto Color Emoji font installed in the cloud image. It preserves the original color glyph and avoids dependence on host fonts. It is distributed under the SIL Open Font License; see NOTO-LICENSE.txt. No font tooling is needed to use the included asset.

Inter is provided by the pinned @fontsource/inter npm package and bundled by Webpack. Its license is included with that package.
